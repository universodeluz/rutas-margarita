# 🚌 Rutero Margarita — Guía de Transporte Público

**Rutero Margarita** es una aplicación web interactiva y Progressive Web App (PWA) diseñada para ayudar a residentes y turistas a consultar la red de transporte público en la Isla de Margarita (Estado Nueva Esparta, Venezuela).

---

## 🚀 Características
* 🗺️ **Mapa Interactivo:** Visualización de recorridos, puntos de origen/destino y terminales clave con Leaflet Maps.
* 🔍 **Filtros Avanzados:** Búsqueda por municipio (Mariño, Maneiro, Marcano, Tubores, Antolín, Díaz, Macanao), tipo de unidad o paradas.
* 💵 **Calculadora de Tarifas:** Conversión de pasajes en dólares referenciales a Bolívares (Bs.).
* 📱 **Soporte PWA:** Instalable directamente en la pantalla de inicio de teléfonos móviles Android y iOS.

---

## 🛠️ Tecnologías utilizadas
* **HTML5 / CSS3:** Diseño responsivo y adaptable a dispositivos móviles.
* **JavaScript (Vanilla):** Lógica de filtrado y cálculo dinámico de tarifas.
* **Leaflet.js:** Renderizado de mapas interactivos y trazado de rutas.
* **FontAwesome:** Iconografía responsiva.
